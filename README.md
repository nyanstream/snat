# @nyanstream/snat

Public client is located in [nyan.stream-next](https://github.com/nyanstream/nyan.stream-next/tree/master/src/components/IndexPageChat) project.

---

To install dependencies:

```bash
bun install
```

To generate Prisma client:

```bash
bun run prisma:generate-client
```

To run:

```bash
bun run start
```

To build docker image:

```bash
docker build --pull --no-cache -t snat-web .
```
